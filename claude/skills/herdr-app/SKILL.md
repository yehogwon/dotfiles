This skill is for the Herdr desktop app, whose command is `herdr-app`. It is
not `herdr`, the older terminal multiplexer: that has its own `herdr` command
and skill.

Use `herdr-app` only to change what the person sees. For starting, reading,
messaging, waiting on or cleaning up agents and programs, use herdr-core
(`hc`) and its skill.

Before using herdr-app, run `herdr-app --skill` and follow it.
